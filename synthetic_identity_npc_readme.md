# Synthetic Identity NPC System

## Overview

Synthetic Identity NPC System is an experimental cognitive architecture for psychologically persistent game NPCs.

This project is not designed as a traditional chatbot NPC framework.
Instead, it attempts to simulate:

- autobiographical memory
- emotional persistence
- suppression and defensive cognition
- self-narrative identity
- endogenous thought activity
- pressure-based behavioral emergence
- long-term psychological continuity

The system treats the Large Language Model (LLM) as a language realization layer rather than the source of cognition.

Core philosophy:

```text
LLM = language realization
Cognition = external persistent architecture
```

The long-term goal is to create NPCs that feel like persistent synthetic personalities rather than reactive conversational agents.

# Key Architectural Principles

## 1. Behavior Emerges From Pressure

NPC behavior is not generated through symbolic scripted rules.

Instead, behavior emerges from competing internal pressures:

- fear
- trust
- shame
- attachment
- survival
- identity defense
- emotional residue
- unresolved conflict

This architecture attempts to simulate psychological tension rather than predefined dialogue paths.

---

## 2. Memory Is Associative, Not Database Retrieval

The memory system is designed as:

```text
emotionally linked autobiographical topology
```

rather than:

```text
flat vector retrieval
```

Memories:

- activate contextually
- spread through associative links
- distort over time
- strengthen through rehearsal
- decay through disuse
- trigger emotional cascades
- bias future cognition

The system combines:

- semantic retrieval
- emotional weighting
- associative traversal
- autobiographical narrative drift

---

## 3. Suppression Is Intercepted Activation

One of the core psychological ideas in the architecture:

```text
suppression != retrieval failure
```

A traumatic memory may:

- activate strongly
- generate emotional disturbance
- increase behavioral leakage
- reduce disclosure probability

This creates:

- avoidance behavior
- discomfort
- tension
- deflection
- hostility
- emotional leakage

instead of artificial silence.

---

## 4. Identity Is Narrative

The system separates:

```text
objective memory
vs
self-narrative memory
```

NPCs do not simply store facts.
They reinterpret experiences to preserve identity coherence.

This enables:

- mythologization
- self-deception
- narrative reframing
- autobiographical drift
- identity defense

---

## 5. Endogenous Cognition

NPCs should continue psychologically existing even without player interaction.

The architecture includes:

- rumination
- spontaneous memory resurfacing
- emotional drift
- unresolved conflict reactivation
- subconscious rehearsal
- latent goal evolution

The objective is:

```text
continuous internal psychological activity
```

rather than:

```text
turn-based reactive dialogue
```

# Main Cognitive Systems

## Memory Engine

Responsible for:

- autobiographical memory storage
- semantic retrieval
- emotional activation
- associative traversal
- memory distortion
- decay and reinforcement

Uses:

- ChromaDB
- NetworkX
- embedding retrieval
- weighted emotional graphs

---

## Suppression System

Responsible for:

- emotional interception
- disclosure inhibition
- avoidance pressure
- behavioral leakage generation

Suppression increases:

- emotional disturbance
- defensive behavior
- conversational tension

while reducing:

- direct disclosure

---

## Goal Engine

Responsible for:

- competing motivations
- desire arbitration
- survival priorities
- trust calculation
- strategic disclosure
- behavioral incentives

Goals dynamically evolve over time.

---

## Attention Engine

Responsible for:

- attentional bottlenecks
- salience competition
- cognitive bandwidth
- stress narrowing
- dominant cognition selection

Humans do not consciously process all activated memories equally.
The system models this limitation.

---

## Emotional Persistence

Responsible for:

- emotional carryover
- mood inertia
- lingering activation
- long-term emotional drift

Painful interactions should influence future cognition.

---

## Self-Concept Defense

Responsible for:

- identity protection
- autobiographical reframing
- shame reduction
- narrative reinterpretation
- self-coherence preservation

The system attempts to preserve:

```text
"who the NPC believes they are"
```

---

## Predictive Simulation

Responsible for:

- anticipated consequences
- conversational forecasting
- betrayal estimation
- social risk evaluation
- strategic silence

NPCs internally simulate:

```text
“If I say this, what happens next?”
```

before responding.

---

## Endogenous Cognition Engine

Responsible for:

- background cognition
- rumination loops
- spontaneous activation
- subconscious rehearsal
- unresolved conflict resurfacing
- emotional baseline evolution

The NPC should feel psychologically persistent even when inactive.

---

## Cognitive Summarizer

Responsible for:

- pressure compaction
- subconscious filtering
- cognitive abstraction
- token-efficient state representation

The LLM should receive:

- behavioral pressures
- dominant tensions
- emotional state summaries

NOT:

- raw cognition traces
- full memory graphs
- complete internal state dumps
